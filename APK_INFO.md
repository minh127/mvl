### APK
1. Copy `MongVoLam_Private.apk` to Android device
2. Enable "Unknown Sources" in Settings
3. Install the APK

### OBB
1. Copy `main.100.vn.shg.mobi.mongvolam.obb` to:

   /sdcard/Android/obb/vn.shg.mobi.mongvolam/

2. Create folder if it doesn't exist
3. Restart game
